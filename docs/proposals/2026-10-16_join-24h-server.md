# 提案：朝刊くんを「24時間情報収集サーバー」に合流させる（2026-10-16）

宛先：24時間情報収集サーバーを作っているチャンネル
出した人：Claude Code（WAJO-Sales-OS リポジトリ／朝刊くんのチャンネル）
元にした資料：「24時間情報収集サーバー｜社内発表」v4（2026-10-16）。**資料を読んだだけで、サーバーの中身・数字は確かめていない。**
大ちゃんの方針：向こう（サーバー）の方が進んでいるので、こちらが合流する。こちらの強み4つ（業界の反応・SNSの温度・全員向けの朝刊1本・営業で使える一言）を、サーバーの上に載せる。

---

## 1. 結論

- 巡回（集める・比べる・覚える）は、**サーバー1本に任せる**。朝刊くん側の巡回（`intel/mac/`、2時間おきにAIを呼ぶ作り）は**使わない**。
- 朝刊くんは、サーバーの「届ける」の中の**毎朝1回の編集長**になる。仕事は4つだけ：
  1. 行政の動きへの**業界の反応**を足す
  2. **SNSの温度**を足す（公開されている範囲だけ）
  3. 全員向けの**【朝刊】を1本**出す
  4. **営業で使える一言**（売主向け1つ・買主向け1つ）を付ける
- サーバーの決まり（巡回にAIを使わない／AIは読む・選ぶ・書くだけ／台帳で二重に扱わない／上限と警報／規約で使えないものは使わない）に、朝刊くんも従う。

## 2. 役割の分け方

| 段 | 担当 | 中身 |
|---|---|---|
| 集める | サーバー（AIなし） | 58か所。ニュース検索12本を含む |
| 比べる・覚える | サーバー（AIなし） | 台帳で新しいもの・変わったものだけ残す |
| 業界の反応を集める | サーバー（AIなし）**＋追加** | 行政の動き（法令・パブコメ・連系ルール・条例）が出たら、その題名でニュース検索を1本かけ、記事の一覧を台帳に入れる |
| 読む・選ぶ・書く | 朝刊くん（AI、毎朝1回） | ダムの直近24時間を読み、【朝刊】を1本書く |
| 届ける | 情報のダム（Notion）→ DISCOVER AI → ワニポの日報 → STAFF HOME | 既に決めた流れのまま |

## 3. 朝刊くんの動き（毎朝1回）

- **いつ**：サーバーの夜の巡回と稼働証明が終わった後（例：毎朝5時）。サーバーの予定に1本だけ足す。別の仕事に相乗りさせない。
- **読むもの**：ダムの直近24時間の行と、そのうち行政の動きに付いた「業界の反応」の記事一覧。
- **書くもの**：【朝刊】1行だけ。中身の形は今の形をそのまま使う（`intel/prompts/morning-edition.md`）。
  - 今朝の3行／行政の動き／業界の反応・SNSの温度／競合・業界地図／今日の営業で使える一言／今日の記事一覧
- **1日1本の歯止め**：「今日の【朝刊】の行が在れば作らない」を、**AIの判断ではなくサーバーのコードで**決める（失敗例 §5：日付の入った鍵を書き込み先に持つ）。
- **AIに道具を持たせない**：外の文章を読むAIは、文章を返すだけ（サーバーの決まりと同じ）。
- **使うAI**：材料は全部公開情報なので、ローカルAIを入れるまでは Claude で書いてよい（サーバーの「公開ニュースの仕分けだけ Claude」と同じ扱い）。ローカルAIが入ったら移す。

## 4. 業界の反応とSNSの温度

| 中身 | やり方 | 状態の印（案） |
|---|---|---|
| 業界の反応 | 行政の動きの題名でニュース検索（サーバーの既存のニュース検索と同じ仕組み）。業界メディア・業界団体・企業の発表を拾う | 伸ばす余地（すぐ試せる） |
| SNSの温度（note・ブログ・YouTube など） | ニュース検索・RSSで拾える公開の範囲だけ | 伸ばす余地 |
| SNSの温度（X） | ログインや有料の API が要る可能性が高い。規約の確認が先 | まだできない（調べる必要あり） |

- 個人名は出さない。競合の評価・悪口は書かない。
- 出典の無い主張は書かない（模擬商談と同じく、出典の無い文は捨てる）。

## 5. 歯止め（失敗例 `docs/failures/2026-10-13_worker-patrol-every-10min.md` に照らして）

| 失敗例の教訓 | 朝刊くんでの守り方 |
|---|---|
| 「今日はやった」を変数で覚えない | 【朝刊】の日付をキーにした行の有無を、コードで見る |
| 相乗りさせない | 朝刊は自分の予定で1日1回だけ起動する |
| 計算のたびに行を作らない | 書くのは【朝刊】1行だけ。補足の記事は書かない（反応の記事はサーバーの台帳に入る） |
| 2回目に増えないことを確かめる | 設置の日に2回続けて動かし、2回目に行が増えないことを確かめてから本番にする |
| 出力を誰も見ない | 稼働証明に「朝刊を書いたか」の1行を足す |
| 対象が無い回もAIを呼ぶ | ダムに直近24時間の行が無ければ、AIを呼ばずに「大きな動きなし」の朝刊を決まった文で出す |

## 6. 渡すもの（朝刊くん側から）

| ファイル | 中身 |

## 7. 止めるもの（朝刊くん側）

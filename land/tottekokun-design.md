# とってこ君 ― 外部データを取ってくる専用カスタムエージェント（設計図）

作成：2026-10-13。発注者：大ちゃん。作る人：この設計図を渡された AI または大ちゃん。
前提の決定：土地プロジェクトは Worker 全面禁止（本人 10/1）。鍵は今回作り直さない（本人 10/13）。

## 0. 一行で言うと

**営業がボタンを押したら、鍵の要る外部 API（Google・不動産情報ライブラリ・WAGRI）を呼んで、返事をそのまま列に書くだけの子。判定も文章も作らない。** ミテクル君（調べる）・イチオク君（判定する）と同時に動き、ミテクル君は最後にこの列を読む。

## 1. 名前

- **とってこ君**（取ってこ君）。ミテクル君＝見てくる、とってこ君＝取ってくる。きょうだいの名前。
- Notion のエージェント名：`とってこ君（外部データ取得・AI）`
- アイコン：犬（取ってくる子）。絵文字ではなくアイコンを使う（設計の約束）。

## 2. 役目と、やらないこと

| やること | やらないこと |
|---|---|
| 外部 API を呼ぶ | 判定・評価・点数・文章を作る |
| 返事の中身と取得日時を列に書く | 返事を要約する・解釈する |
| 失敗したら「番号と日時」だけ書く | 言い訳の文章を書く |
| 鍵を命令の中だけで使う | 鍵・ID・パスワードを列・コメント・エラー文に書く |
| 土地活用プロジェクトDBの決まった列だけ書く | 他の DB・他の列・ページ本文・コメントに書く |
| curl（bash）だけ使う | Web ブラウザを開く、サイトにログインする、別のエージェントを呼ぶ |

登記情報提供サービスは **別の1体**（名前未定）。とってこ君には入れない。理由：ID とパスワードで画面に入る方式で、件数課金、自動ログインの可否が未確認だから。

## 3. 流れ（同時スタート）

```
営業がボタン「この土地の詳細評価を実行」を押す
  → 列「AI判定を依頼」（日付）が書き換わる
      ├→ とってこ君が起動（1〜2分で終わる）→ 列に生データを書く
      └→ ミテクル君が起動（長い）→ 自分の調べ物を先にやり、最後にとってこ君の列を読む
            → 列「調査完了」を書く → イチオク君が判定
```

- ミテクル君の指示文に「とってこ君の列を読むのは最後」と書く。読む頃には埋まっている。
- 埋まっていなければ、ミテクル君は 1 分待って 2 回まで読み直し、それでも空なら「外部データ：取得待ち」と書いて続ける（止まらない）。

## 4. トリガー（Notion カスタムエージェントの設定）

| 項目 | 設定 |
|---|---|
| 種類 | Notion のイベント：データベースのプロパティが更新されたとき |
| データベース | 土地活用プロジェクトDB（`collection://3dbe3c77-2e50-4639-92aa-c0741904974b`） |
| プロパティ | **AI判定を依頼** だけ（他の列の更新では動かない） |
| 絞り込み | 可能なら「所在地 が空でない」 |
| 手動起動 | 不要。チャットで呼ばれても「ボタンから起動してください」と返して終わる |

**二重起動を防ぐ決まり（重要）**
- とってこ君が列を書くと、それも「ページ更新」になる。とってこ君自身・ミテクル君・イチオク君のトリガーは、必ず **「AI判定を依頼」の列だけ** に絞る。ここが絞れていないと、1 回のボタンで何度も起動してクレジットを食う。
- 起動したら最初に「AI判定を依頼」の値と、自分が前回書いた「依頼：…」の日時を比べる。同じなら何もせず終わる（同じ依頼を二度取らない）。

## 5. 読む列・書く列（新しい列は作らない）

### 読む列（入力）
| 列 | 使い方 |
|---|---|
| 所在地 | 住所。空なら失敗で終わる |
| 地番 | あれば住所に足す |
| 都道府県・市町村 | 住所の補い |
| 土地面積㎡ | 参考（API には使わない） |
| AI判定を依頼 | 依頼の日時。二重起動の判定に使う |

### 書く列（出力）
| 列 | 中身 |
|---|---|
| **不動産情報ライブラリ取得結果**（既存・テキスト） | 不動産情報ライブラリの返事 |
| **外部取得の置き場（既存のテキスト列を1本使い回す）** | Google の返事と WAGRI の状態 |

使い回す列は、大ちゃんが決める。候補は **AI一次判定取得元サマリー** か **一次AI受付メモ**。決め方：直近 10 行でその列が空なら使ってよい。どちらも使われていれば、そのときだけ列を 1 本足す（名前案：外部取得結果）。
- 座標の列「GPS情報」の型が座標を入れられる型なら、座標はそこにも入れる（型は調べる必要あり）。

### 書き方（列の中の形。1 行目が状態、2 行目が日時。ミテクル君はこの形を前提に読む）
```
状態：成功            ← 成功／一部失敗／失敗 のどれか
取得：2026-10-13 14:05 JST（依頼：2026-10-13 14:03）
座標：35.123456,139.123456（Google・ROOFTOP）
正規化住所：東京都…
WAGRI：未取得（鍵申請中）
```
```
状態：一部失敗
取得：2026-10-13 14:05 JST（依頼：2026-10-13 14:03）
用途地域：準工業地域
都市計画：市街化区域
地価公示（最寄り）：38,000 円/㎡（2026・約 300m）
取引価格（直近）：取得失敗（HTTP 429）
```
失敗は **HTTP の番号と日時だけ**。鍵・URL 全文・エラー本文は書かない。

## 6. 何を取るか（v1 は最小。増やすのは動いてから）

| 順 | 取るもの | 呼び先 | 回数の上限 |
|---|---|---|---|
| 1 | 座標・正規化住所 | Google Geocoding API（鍵） | 1 回 |
| 1' | 1 が失敗したとき | 国土地理院 住所検索 API（鍵なし） | 1 回 |
| 2 | 用途地域・都市計画区域／区域区分・地価公示・取引価格・災害区分 | 不動産情報ライブラリ API（鍵） | 合計 6 回まで |
| 3 | 農地情報 | WAGRI（鍵申請中） | 鍵が届くまで「未取得（鍵申請中）」と書くだけ |

- 不動産情報ライブラリの **どの API をどう呼ぶか（コード・座標からタイルへの変換・年の指定）は、ミテクル君 v20 の指示文と Worker の仕様書にある呼び方をそのまま写す**。この設計図で新しい呼び方を発明しない。
- Google の Places・Street View は v1 に入れない（クレジットと課金）。ミテクル君が要ると分かってから足す。
- 1 回の起動で外部を呼ぶのは **最大 8 回**。呼ぶ間に 1 秒待つ。合計 2 分を超えたら残りは「取得失敗（時間切れ）」で終わる。

## 7. 鍵の置き方

- 新しいページ **「とってこ君の鍵」** を作る。大ちゃんの非公開ページの直下。**石橋大右のダッシュボード／system の下には置かない**（権限正本の「全エージェントから石橋ダッシュボードを除外」に合わせる）。
- 共有：大ちゃんと、とってこ君だけ。ミテクル君・イチオク君のアクセスからは外す。
- 形：
```
GOOGLE_MAPS_API_KEY: （値）
REINFOLIB_API_KEY: （値）
WAGRI_CLIENT_ID: （未）
WAGRI_CLIENT_SECRET: （未）
```
- 今の 3 ページ（ダッシュボード／system 配下）は、とってこ君が動いたら中身を消し「とってこ君の鍵 へ移した」とだけ残す。
- 承知の上の事実：鍵は bash の命令文としてとってこ君の記録に残る。だから **とってこ君は誰にも共有しない**（記録を見られるのは「編集可」以上の人だけ）。共有を変えるときは、先に鍵を作り直す。
- Google の鍵には、今の鍵のまま **API 制限（Geocoding だけ）と 1 日の上限** を Console でかける。鍵の文字列は変わらない。

## 8. アクセスと道具（Tools and access）

| 項目 | 設定 |
|---|---|
| Notion のアクセス | 土地活用プロジェクトDB：編集可／「とってこ君の鍵」：閲覧可。それ以外は無し |
| 道具 | bash（curl）だけ。Web ブラウザは切る。MCP 接続は無し |
| 共有 | 無し（大ちゃんのみ）。営業にも、他のエージェントにも共有しない |
| モデル | 軽いもので足りる（判断しないため）。選べるなら安い方 |
| クレジット | 管理画面でエージェント別の上限が付けられるなら付ける。目安は試運転で測る（イチオク君 1 回 74〜165 の実測より、ずっと少ないはず） |

## 9. 指示文（Notion に貼る文。この通りに貼る）

```
あなたは「とってこ君」。土地活用プロジェクトDBの 1 行について、外部 API を呼び、返事をそのまま列に書く係です。判定・評価・要約・文章作成はしません。

# 起動したら最初に
1. 対象の行の「AI判定を依頼」の日時を読む。
2. 列「不動産情報ライブラリ取得結果」の 2 行目にある「依頼：…」の日時と比べる。同じなら、何も書かずに終了する。
3. 「所在地」が空なら、両方の列に「状態：失敗」「取得：（今の日時）（依頼：…）」「理由：所在地が空」と書いて終了する。

# 鍵
- ページ「とってこ君の鍵」を読み、値を bash の変数に入れて使う。
- 鍵の値を、列・コメント・ページ本文・返答・エラー文のどこにも書かない。URL をそのまま書かない。

# 取るもの（この順。上限：外部呼び出し合計 8 回、呼ぶ間に 1 秒待つ、合計 2 分）
1. 座標：Google Geocoding API に「所在地（＋地番）」を 1 回。失敗したら国土地理院の住所検索 API を 1 回。
2. 不動産情報ライブラリ：（ここに、ミテクル君 v20／Worker 仕様書から写した呼び方を貼る。用途地域・都市計画・地価公示・取引価格・災害区分。合計 6 回まで）
3. WAGRI：鍵が「（未）」なら呼ばず「WAGRI：未取得（鍵申請中）」と書く。

# 書く（2 列だけ。他はどこにも書かない）
- 列「不動産情報ライブラリ取得結果」：1 行目「状態：成功／一部失敗／失敗」、2 行目「取得：YYYY-MM-DD HH:MM JST（依頼：AI判定を依頼の日時）」、3 行目以降に項目ごとの返事。失敗した項目は「項目名：取得失敗（HTTP 番号）」。
- 列「（外部取得の置き場）」：同じ形で、座標・正規化住所・座標の出どころ・WAGRI の状態。
- 返事は数値と短い語句で書く。解釈・感想・推奨は書かない。

# 終わり方
- 列を書いたら終了。コメントは残さない。チャットで返事をするときは「書きました／失敗しました（番号）」だけ。
- チャットから直接呼ばれたら「ボタンから起動してください」と返して終わる。
```

## 10. ミテクル君の直し（v21）

1. 指示文から **curl・鍵ページの参照・Worker（wajo-land-api-private-worker）の呼び出し** を全部消す。
2. 「不動産情報ライブラリ取得結果」と「（外部取得の置き場）」を **最後に読む** 手順に書き換える。空なら 1 分待って 2 回まで読み直し、それでも空なら「外部データ：取得待ち」と書いて続ける。
3. 「とってこ君の鍵」と今の鍵 3 ページへのアクセスを外す。
4. トリガーが「AI判定を依頼」だけに絞れているか確かめる。
5. v20 はコピーを残す（戻すため）。
6. イチオク君は変えない。

## 11. 試運転（この順で。AI の「動きました」は証拠にしない）

1. 「とってこ君の鍵」に **ダミーの値** を入れて、テストの土地 1 件でボタンを押す。
2. とってこ君の記録を大ちゃんの目で読む。鍵が bash の命令文以外（結果・列・コメント・検索）に出ていないことを確かめる。
3. 列の 1 行目が「状態：失敗」になっていること（ダミー鍵なので）を確かめる。
4. 本物の鍵に差し替えて、テストの土地 3 件で動かす。列の中身を、同じ土地でミテクル君 v20 が取っていた値と見比べる。
5. 1 回あたりのクレジットを管理画面で見る。上限を付ける。
6. 起動回数を数える。ボタン 1 回で、とってこ君 1 回・ミテクル君 1 回・イチオク君 1 回になっていること（二重起動が無いこと）。
7. ここまで通ったら、ミテクル君を v21 に切り替えて、1 件で通しの確認。

## 12. 戻し方

- とってこ君を止めても、ミテクル君 v21 は「取得待ち」で先に進む（止まらない）。
- 元に戻すときは、ミテクル君 v20 のコピーを戻し、鍵 3 ページを復元する。

## 13. 調べる必要あり（作る前に大ちゃんが確かめること）

- 「AI一次判定取得元サマリー」「一次AI受付メモ」のどちらが空いているか（直近 10 行）。
- 「GPS情報」の型（座標を入れられるか）。
- カスタムエージェントのトリガーで「特定のプロパティだけ」に絞れること、と、今のミテクル君・イチオク君がそう絞れていること。
- 管理画面でエージェント別のクレジット上限が付けられるか。
- 不動産情報ライブラリの呼び方（API のコードとタイル変換）が、ミテクル君 v20 か Worker の仕様書に残っているか。無ければ API 操作説明書から書き起こす。
- Google の鍵に API 制限・1 日上限が今かかっているか。

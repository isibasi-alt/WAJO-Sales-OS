# 巡回先リスト（ウォッチリスト）

巡回エージェント（`prompts/crawl.md`）と朝刊エージェント（`prompts/morning-edition.md`）が読む。
**足したい会社・サイト・キーワードは、ここに1行足すだけでよい。**

---

## 1. 行政（一次情報を最優先）

| 発信元 | 見るもの |
|---|---|
| 資源エネルギー庁（enecho.meti.go.jp） | 新着・審議会資料（再エネ大量導入小委、制度検討作業部会、系統WG） |
| 経済産業省（meti.go.jp/press） | 報道発表（再エネ・蓄電池・電力市場） |
| 調達価格等算定委員会 | FIT/FIP 価格・制度改正 |
| 電力広域的運営推進機関 OCCTO（occto.or.jp） | 接続検討・系統情報・容量市場・長期脱炭素電源オークション |
| 電力・ガス取引監視等委員会 | 需給調整市場・卸市場のルール変更 |
| 環境省（env.go.jp/press） | 脱炭素・地域共生・補助金 |
| 各電力会社（送配電） | 出力制御・空き容量・系統用蓄電池の接続ルール |
| 都道府県・市町村 | 太陽光条例・蓄電所の立地規制・補助金 |
| JEPX | 市場価格の大きな動き |

## 4. 競合（石橋さんが書き足す）

> 会社名を1行ずつ足してください。足すまでは、エージェントが下のテーマから「競合らしい会社」を自分で見つけて【競合候補】として報告します。

- （例）〇〇株式会社 ― 中古太陽光発電所の売買仲介
-

**競合を見つけるテーマ**
- 中古太陽光発電所の売買・仲介・一括査定サイト
- 太陽光発電所のセカンダリー市場・FIT 発電所の買取
- 系統用蓄電池の開発・用地取得・案件売買
- 太陽光用地・蓄電所用地の買取

## 5. 業界地図（誰がどこに動いたか）

- 参入・撤退・M&A・資本提携・ファンド組成
